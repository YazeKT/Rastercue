# Local data and networking

Rastercue does not collect analytics, upload images or upload logs. Processing uses the inherited local engine. History stores image thumbnails, filenames, paths and job settings locally; these can be sensitive. Protect your history folder and exports. Clearing history does not delete source images or upscaled outputs.

Rastercue uses its own application-data directory, not Upscayl's. History can be relocated explicitly. The original folder is retained during relocation. Settings reset is separate from history deletion.

Automatic update checks/downloads contact Rastercue's GitHub Releases. Disable automatic updates in Application settings. Explicit model, creator, licence, upstream and troubleshooting links open external websites subject to their policies. Offline processing does not require these links.

No new cloud service or image download feature is included. Local diagnostics may include paths and machine information; inspect them before sharing an exported log.
