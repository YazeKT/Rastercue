# Rastercue support

Rastercue is maintained by Kirsten Trimaley / Yaze Media (YazeKT).

- Email: [kirstentrimaley@gmail.com](mailto:kirstentrimaley@gmail.com)
- Questions and reproducible bugs: [GitHub Issues](https://github.com/YazeKT/Rastercue/issues)
- Security reports: follow [SECURITY.md](SECURITY.md)
- Changelog: [CHANGELOG.md](CHANGELOG.md)
- User and technical guides: [docs/README.md](docs/README.md)

Before reporting a problem, record the Rastercue version, failed phase, error code, selected and actual device, input dimensions, model and relevant settings. Use a non-confidential sample where possible.

Review support bundles before sharing. Remove private images, filenames, paths, usernames, customer information and anything else you do not want to disclose. Rastercue does not automatically upload diagnostics.
