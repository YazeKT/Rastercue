# Rastercue

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Graphic designers inspecting enlarged photographs, artwork, edges and text at work and at home. Desktop distribution for Windows, macOS and Linux through Electron.

## Product Purpose

Preserve the proven Upscayl processing engine while making model choice, output inspection, settings and job records easier to understand.

## Capabilities and Constraints

Engine binaries, arguments, model IDs, native scale detection, conversion and processing commands are protected. History, renaming and viewing tools are additive. Both sidebars remain visible; 1366×768 at 100% scaling is the compact target. Long content can scroll, everyday controls use tab paging. New installations default to JPG and dark mode. Existing explicit preferences remain intact.

## Brand Commitments

Rastercue, selected geometric R-and-pixel identity. Periwinkle #A5A0FF, graphite #14161B, slate #22252D, text #F1F2F6. Small Upscayl attribution with complete licence notices. No telemetry or cloud promotion. Updates come only from the eventual YazeKT/Rastercue GitHub Releases repository.

## Product Principles

- Preserve working processing behaviour and user files.
- Maximise preview space without hiding sidebars.
- Explain settings and model limits honestly.
- Keep job history locally with records and thumbnails, not duplicate output archives.
- Verify packaged behaviour; configuration alone is not proof of platform support.

## Evidence on Hand

Original source and bundled engine/model files. Seven built-in models and fourteen paired custom models in the sibling custom-models-main folder. Original production build and Windows GPU baseline. Selected logo proof supplied in the approved plan. No confirmed trademark clearance or macOS signing credentials.
