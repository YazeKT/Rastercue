Rastercue is based on Upscayl's application source. Original copyright/authorship belongs to Nayam Amarshe, TGS963 and the Upscayl contributors; existing source notices and the original AGPL-3.0 LICENSE are retained. This extracted working tree had no upstream Git history, so this repository starts with a documented source snapshot rather than claiming to preserve upstream commit history.

Rastercue modifications, September2026: Yaze Media / YazeKT. Modified areas include product identity, compact workstation interface, model guidance, inspection tools, job history/managed naming, logs, privacy removals, release identity and a narrow alpha-input JPEG safeguard. Original processing command handlers, engine arguments, model IDs and baseline binaries/weights were preserved locally. SHA-256 reference: tests/engine-baseline.json.

Native foundation: Upscayl-NCNN (AGPL-3.0), derived from Real-ESRGAN-ncnn-vulkan and its contributors. Real-ESRGAN's separate BSD-3-Clause notice is retained in Real-ESRGAN_LICENSE.txt; this does not replace the native fork's AGPL licence.

Models retain creator authorship and their own terms. No native binaries/model weights are part of this initial source publication. Separate rights/provenance review is required before redistribution. No endorsement by upstream creators is implied.

Rastercue brand SVG geometry was manually reconstructed from the user-selected generated proof; generated texture is not retained. Production icons are deterministic renders of that master. The Poppins font's SIL OFL notice is retained in resources/brand/Poppins-OFL.txt.
